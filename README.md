# Study Classroom for Android

This repository holds only the releases of the Study Classroom Android app: each release has the signed APK and what is new in it. There is no code here.

- Install: download the newest APK from **Releases**, or from the classroom website (Get the app, Download for Android).
- Updates: the app checks the classroom server, which follows the releases here, and updates itself (or shows Update at the top when automatic updates are off).
- Android installs an update only when it is signed with the same key as the app already on the phone.
